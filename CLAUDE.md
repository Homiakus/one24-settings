# CLAUDE.md — settings-modbus

## Что это

Подпроект ONEPAP.24 — документация и конфигурация Modbus RTU протокола для связи с контроллером цитологического процессора.

**Родительский проект:** `[[../README|ONEPAP.24]]` — автоматизированный цитологический процессор (24 стекла, окраска по Папаниколау).

## Назначение

Этот каталог содержит **единственный источник истины** для Modbus-регистров и протокола обмена с PLC (ESP32 / Medtechnica). Здесь:

- Описана полная карта регистров (операционных и сервисных)
- Задокументированы алгоритмы взаимодействия с регистрами
- Определены коды команд, коды ошибок и их отображение на UI
- Описаны сценарии окраски и промывки

## Технический контекст

### Аппаратный стек
- **Контроллер:** ESP32-based плата Medtechnica
- **Интерфейс:** Modbus RTU через UART/USB (COM4)
- **Параметры:** 115200 бод, 8N1, slave_id=1
- **Исполнительные устройства:** шаговые двигатели (NEMA17 + TMC2209), соленоидные клапаны, вакуумный насос, пережимные клапаны
- **Датчики:** концевики (LJ8A3-2-Z/BX), тензодатчик (HX711), датчик жидкости, ультразвуковой датчик уровня

### Программный стек
- **Язык:** Go 1.22 (управляющее ПО)
- **UI:** Web/htmx SPA (Wails v2 + WebView2)
- **Конфигурация:** TOML (BurntSushi/toml)
- **Modbus-библиотека:** goburrow/modbus
- **Симуляция:** Test Control Module (tcm_v2) для отладки без железа

### Связанные каталоги
- `../11_Software/Main-v6/` — исходный код ПО управления
- `../11_Software/Main-v6/config/fsm/screens/` — FSM-конфиги экранов (исполняемый источник истины)
- `../09_архив/Wails-v2/labflow/config/` — архивные TOML-конфиги (base_config.toml, user_settings.toml)

## Правила работы с документацией

1. **Один факт — один документ.** `Протокол_Modbus.md` — единственный источник истины для Modbus-регистров.
2. **При расхождении** с FSM-конфигами (`screens/*.toml`) — FSM-конфиги авторитетны.
3. **При расхождении** с архивным `base_config.toml` — этот документ авторитетен.
4. **Язык:** русский (документация), английский (ключи TOML, имена регистров, код).
5. **Изменения** в карту регистров должны отражаться в ревизии документа (`revision: N`).

## Протокол окраски (быстрая справка)

11 шагов Папаниколау: Спирт → Гематоксилин → Вода → Вода → Спирт → OG → Спирт → EA → Спирт → Спирт → Спирт

Промывка: 4 шага (хлорка ×2, вода ×2) с кодами жидкости вместо номеров.

## Разработка

### При изменении карты регистров
1. Обновить `Протокол_Modbus.md` (этот каталог)
2. Проверить соответствие FSM-конфигов (`screens/*.toml`)
3. Обновить `base_config.toml` и `modbus.toml` в ПО
4. Обновить ревизию и дату в YAML frontmatter

### При добавлении новых регистров
1. Согласовать адрес с прошивкой контроллера (избегать конфликтов с сервисной картой 0..34)
2. Добавить в карту регистров с указанием R/W, типа, диапазона
3. Написать алгоритм использования (Modbus-операции, валидация, обработка ошибок)
4. Добавить в `modbus.toml` конфигурацию
