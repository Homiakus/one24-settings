# JSON-профили настроек ONEPAP.24

Конфигуратор поддерживает экспорт и импорт полного рабочего профиля в JSON.

## Что входит в профиль

- последовательный порт, скорость и Slave ID;
- 11 шагов протокола Папаниколау;
- время экспозиции и объём налива каждого шага;
- порог детекции пустого реагента;
- 15 координат селектора 1;
- 15 координат селектора 2;
- названия шагов и позиций для читаемости файла.

В файл не входят текущие показания датчиков, ошибки, журнал, состояние выполняемой программы, PID сервера и другие временные данные.

## Безопасный сценарий импорта

1. Нажать **Импорт JSON**.
2. Выбрать файл размером не более 1 МБ.
3. Конфигуратор проверит версию схемы, количество элементов, уникальность ID и диапазоны всех чисел.
4. В окне подтверждения будет показано количество изменяемых шагов и координат.
5. После подтверждения значения появятся в интерфейсе как изменения.
6. Проверить выделенные строки.
7. Отдельно нажать **Записать изменения** в разделе шагов и в разделе координат.

Импорт сам по себе ничего не записывает в PLC. Если контроллер уже подключён, параметры COM-порта из файла не меняют активное соединение.

## Формат

```json
{
  "schema": "onepap24-settings",
  "schema_version": 1,
  "exported_at": "2026-08-03T10:30:00.000Z",
  "application": {
    "name": "ONEPAP.24 Modbus Configurator",
    "version": "1"
  },
  "device": {
    "port": "COM4",
    "baudrate": 115200,
    "slave_id": 1
  },
  "staining": {
    "protocol": "pap_stain",
    "reagent_empty_delta": 10,
    "steps": []
  },
  "selectors": {
    "selector1": [],
    "selector2": []
  }
}
```

## Ограничения схемы версии 1

| Поле | Ограничение |
|---|---|
| `device.baudrate` | целое число 1200–4000000 |
| `device.slave_id` | 1–247 |
| `staining.steps` | ровно 11 элементов, ID 1–11 без повторов |
| `exposure_time` | 1–600 секунд |
| `fill_volume` | 1–6000, мл × 10 |
| `reagent_empty_delta` | 0–255 |
| каждый селектор | ровно 15 позиций, отверстия 0–14 без повторов |
| `coord` | 0–65535 |

Неизвестные поля отклоняются, чтобы опечатка в названии параметра не была silently проигнорирована.
