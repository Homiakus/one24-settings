## 2. Иерархия пакетов

| Пакет | Назначение | Фоновые горутины | Защита конкурентности |
|---|---|---|---|
| `main` | Точка входа, парсинг флагов, инициализация HTTP и Modbus | `httpServer.Serve`, `signal.Notify` | Отсутствует (топовый компонент) |
| `configurator/config` | Загрузка TOML конфигурации | Нет | Immutable после загрузки |
| `configurator/model` | Определения структур данных | Нет | Отсутствует |
| `configurator/ws` | Управление WebSocket клиентами и вещание событий | `writePump`, `readPump` на каждого клиента | `Hub.mu` (`sync.RWMutex`) |
| `configurator/modbus` | Modbus RTU клиент, повторы, высокоуровневые команды | Потоковые вызовы `WaitReady`, `SendCommand` | `Client.mu` (`sync.Mutex`) |
| `configurator/api` | REST API роутер, middleware, выполнение программ | Асинхронные программы в фоновых горутинах | `ServerState.mu` (`sync.RWMutex`) |

## 3. Синхронизация и блокировки

- `modbus.Client.mu`: монопольный доступ к RS-485 COM-порту (Modbus RTU — строго один запрос за раз).
- `ws.Hub.mu`: защита реестра подключенных клиентов `map[*client]struct{}`.
- `ServerState.mu`: защита оперативного состояния шагов (`Steps`), лога (`Log`) и сигнального канала возобновления при отсутствии реагента (`reagentResume`).
